Политика конфиденциальности Family Security

1. Общие положения и назначение приложения

Family Security — это специализированное приложение для родительского контроля и обеспечения детской безопасности. Приложение помогает родителям заботиться о детях, отслеживать их текущее местоположение на карте, получать уведомления о входе/выходе из безопасных зон и контролировать экранное время. Использование приложения осуществляется с явного согласия родителей или законных представителей.

2. Собираемые данные и цели их обработки

  • Учетные данные: логин, имя, роль пользователя (родитель или ребёнок), код сопряжения устройств, фото профиля (по желанию). Используются для аутентификации и связывания родительского и детского аккаунтов.
  • Данные геолокации и фоновое местоположение: точные GPS-координаты устройства ребёнка, история перемещений, статус безопасных зон. Собираются для отображения ребёнка на карте родителя в реальном времени, отправки экстренных SOS-сигналов и автоматических уведомлений о прибытии/уходе из безопасных зон.
  • Информация об устройстве: уровень заряда батареи, состояние зарядки, модель и версия операционной системы, часовой пояс. Используются для уведомления родителя о разряженном телефоне ребёнка.
  • Данные об использовании приложений и блокировка (Android): список установленных приложений для настройки разрешённых/запрещённых программ родителями и статистика времени работы программ.
  • Аудио по запросу (микрофон): кратковременная звуковая трансляция окружающего звука активируется исключительно по прямому запросу родителя при наличии выданного разрешения микрофона. Запись не ведётся в постоянном фоновом режиме.
  • Семейный чат и задачи: сообщения, задания с наградами и прикрепленные файлы между родителем и ребенком.

3. Использование данных о местоположении в фоновом режиме (Background Location)

Уведомление о фоновом доступе: Family Security собирает данные о местоположении устройства ребёнка даже тогда, когда приложение закрыто, находится в фоновом режиме или не используется. Это необходимо для того, чтобы:

  • Родитель мог в любой момент увидеть актуальное местоположение ребёнка на карте для обеспечения его безопасности.
  • Приложение могло отправить родителю автоматическое уведомление, если ребёнок вышел из безопасной зоны (например, из школы или дома).
  • При нажатии ребёнком кнопки SOS родитель немедленно получил точные координаты экстренной помощи.

Координаты передаются по защищенному протоколу HTTPS и доступны исключительно привязанному аккаунту родителя. Данные о местоположении никогда не продаются и не используются для рекламных целей.

4. Использование AccessibilityService API (Специальные возможности)

Назначение AccessibilityService: На устройствах под управлением Android приложение Family Security использует AccessibilityService API исключительно для реализации функции родительского контроля «Блокировка приложений» и контроля экранного времени.

  • Сервис определяет имя пакета запущенного на переднем плане приложения.
  • Если открытое приложение входит в список запрещённых родителем программ, Family Security отображает экран блокировки и закрывает доступ.

Гарантия конфиденциальности: AccessibilityService API НЕ используется для чтения текста на экране, записи нажатий клавиш (кейлоггинга), доступа к личным сообщениям, фотографиям, паролям или платежным реквизитам. Данные специальных возможностей не собираются, не сохраняются на сервере и не передаются третьим лицам. Приложение не позиционируется как средство доступности для лиц с ограниченными возможностями здоровья (isAccessibilityTool=false).

5. Передача данных третьим лицам и сторонние сервисы

Мы не продаем и не передаем персональные данные сторонним рекламным сетям. Для обеспечения стабильной технической работы приложения используются следующие проверенные поставщики услуг:

  • Google LLC (Google Play Services, Google Maps API): отображение карты и геокодирование адресов.
  • Firebase Cloud Messaging (Google LLC): доставка служебных push-уведомлений о безопасности родителям и детям.
  • RevenueCat Inc.: обработка и проверка статуса подписки Google Play Billing.

6. Безопасность и шифрование данных

Все данные при передаче между приложением и нашими серверами шифруются с использованием стандартных криптографических протоколов HTTPS / TLS 1.3. Доступ к данным ребёнка строго разграничен и возможен исключительно с авторизованного родительского аккаунта, прошедшего сопряжение.

7. Удаление аккаунта и срок хранения данных

Пользователи могут в любой момент удалить свой аккаунт и все связанные данные непосредственно в приложении: Настройки > Аккаунт > Удалить аккаунт или через специальную веб-страницу: https://baby-locator-web.vercel.app/delete-account.html.

При удалении аккаунта все персональные данные, профили детей, история местоположений, чаты и настройки безвозвратно удаляются из активной базы данных немедленно и полностью стираются из резервных копий в течение 30 дней.
